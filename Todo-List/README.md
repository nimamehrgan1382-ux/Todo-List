# Todo List

یک برنامه ساده برای مدیریت کارهای روزانه با JavaScript.

## امکانات

- افزودن کار جدید
- حذف کار
- علامت‌گذاری کار به عنوان انجام‌شده
- فیلتر کارها
- حذف همه کارها

## تکنولوژی‌ها

- HTML
- CSS
- JavaScript
- LocalStorage

## اجرای پروژه

1. فایل `index.html` را در مرورگر باز کنید.
2. یا پروژه را با Live Server اجرا کنید.
